# 📖 About

This repository contains organized **Human Resource Management (HRM)** study notes collected throughout the course.

The purpose of these notes is to simplify complex HR concepts and provide students with an easy-to-understand study resource for academic success.

Whether you're preparing for a quiz, assignment, midterm, or final exam, these notes offer a structured way to review the course content.
